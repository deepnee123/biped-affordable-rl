# Low-Cost Bipedal Robot via Reinforcement Learning

A personal passion project focused on achieving robust bipedal locomotion using highly accessible, 3D-printed hardware and machine learning control.

## Current State
- [x] Basic physical structure conceptualized and realized in CAD
- [/] Setting up simulation and hardware architecture (In Progress)
- [ ] RL Policy training using Genesis world, currently working on making a working URDF file that doesnt break when in simulation

## System Constraints & Goals
- **Budget:** Under $1000, using easily accessable parts via amazon/aliexpress
- **Manufacturing:** 3D-printed PLA/PETG parts
- **Control:** Blind locomotion utilizing IMU and joint feedback, able to jump, walk, run
